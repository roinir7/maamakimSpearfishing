# מעמקים · Ma'amakim Spearfishing Israel

אתר קהילתי דו-לשוני (עברית RTL / אנגלית LTR) ומותאם למובייל לצוללים חופשיים ודייגי צלילה חופשית בחופי ישראל.

## תכונות עיקריות
- **מפה אינטראקטיבית ותחזית ים חיה (Open-Meteo Marine & Weather API):** גובה גלים, כיוון וזמן מחזור (Swell), רוח, טמפרטורת מים ומדד התאמה צבעוני (*מתאים / גבולי / לא מתאים*) + ציר 24 שעות וגרף 48 שעות.
- **מדד ראות תת-ימית משוקלל:** שילוב מודל ים + דיווחים חיים של צוללים מהמים.
- **דיווחים בלייב מהמים ויומן תפיסות:** העלאת דיווחי ראות/זרם/מדוזות והעלאת תפיסות כולל תמונות (נשמר ב-`localStorage` בדמו, מוכן לחיבור ל-Backend).
- **בטיחות, תקריות ורישיון דיג:** תזכורת ולינקים רשמיים להנפקת/חידוש רישיון דיג (משרד החקלאות) ותקנות רשות הטבע והגנים (רט״ג), לוח תקריות בטיחות קהילתי (כולל אפשרות לדיווח אנונימי) וטבלת אורכי מינימום חוקיים.
- **מגדיר תמונות לדגי הים התיכון והשוואת חפאש:**
  - אזהרת חוק בולטת והשוואה ויזואלית מפורטת בין **חפאש / דקר אלכסנדרוני** (*Epinephelus costae* — ערך טבע מוגן ואסור בדיג מאפריל 2021) לבין הלוקוסים הדומים לו המותרים בדיג (≥ 40 ס״מ: **לוקוס לבן**, **דאור/דקר הסלעים** ו**ארדי/דוקרנית אדומה**).
  - מגדיר תמונות עם חיפוש וסינון לדגים נפוצים בריפי ישראל, כולל סימון דגים פולשים ארסיים (**זהרון הדור**, **סיכן משויש / אראס**) שמותר לדוג בזהירות.
- **מותאם למובייל + PWA + מצב כהה/בהיר + עברית/אנגלית.**

## מבנה הפרויקט
```text
maamakimSpearfishing/
├── index.html              # דף האתר הראשי
├── css/
│   └── styles.css          # משתני עיצוב (כהה/בהיר), RTL/LTR ומובייל
├── js/
│   └── app.js              # לוגיקת תחזית, מפה, דיווחים, בטיחות, מגדיר דגים ותרגום
├── assets/
│   ├── icon.svg            # אייקון האתר וה-PWA
│   └── fish/*.webp         # 12 תמונות מותאמות של דגי הים התיכון
├── manifest.webmanifest    # הגדרת PWA להוספה למסך הבית בטלפון
└── README.md
```

## הרצה מקומית
אין צורך בשלב Build — אפשר להריץ ישירות עם כל שרת סטטי:
```bash
npx serve .
# או עם Python:
python3 -m http.server 8080
```
ואז לפתוח בדפדפן `http://localhost:8080`.

## פרסום בחינם ב-GitHub Pages (גישה מהטלפון הנייד)
1. היכנסו ל-**Settings → Pages** בריפוזיטורי ב-GitHub.
2. תחת **Build and deployment**, בחרו **Deploy from a branch** → ענף `main` ותיקיית `/ (root)` ולחצו **Save**.
3. בתוך כדקה האתר יהיה זמין בכתובת:
   `https://<username>.github.io/maamakimSpearfishing/`
   וניתן להוסיף אותו למסך הבית בטלפון (iOS Safari: *שתף ← הוסף למסך הבית*, Android Chrome: *התקן אפליקציה*).
